# Classworks

面向班级电脑使用的作业看板。

## 当前功能

- 按日期记录当天作业
- 固定学科入口：语文、数学、英语、物理、化学、地理
- 作业卡片按内容高度自动排布
- 关闭编辑卡片时自动保存
- 地理卡片支持 HDR 光扫和 AI 润色审批
- 支持字体、字号、日期切换和复制到今天
- 云端同步默认开启，**无需任何密钥/鉴权**，开箱即用
- 支持 PWA 安装
- 已设置 `robots.txt` + `noindex` 元标签 + `X-Robots-Tag`，禁止搜索引擎索引

## 开发

```bash
pnpm install
pnpm dev
pnpm build
```

默认开发端口为 `3031`。

## 部署

当前项目以 `EdgeOne Pages` 为主，构建输出目录为 `dist/`。

## 说明

项目已移除考试编辑器、签到、消息音效和其他旧演示残留，当前代码只保留作业看板主流程。
